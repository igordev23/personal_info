Projetos

Chat Code

Chat de bate-papo online para programadores.

O ChatCode é uma plataforma web de bate-papo online para programadores onde os usuários podem conversar, compartilhar ideias e colaborar em tempo real. O diferencial é a presença de um bot com Inteligência Artificial integrado ao chat, capaz de ajudar na resolução de dúvidas e até mesmo de executar códigos JavaScript ou TypeScript diretamente no chat, tornando a experiência mais dinâmica e educativa, ideal para programadores iniciantes.

Cardápio Online

Cardápio online de pizzaria com carrinho e pedido via WhatsApp.

O Cardápio Online de Pizzaria é uma plataforma web que permite aos usuários selecionar seus itens de pedido (pizzas, bebidas, acompanhamentos) de forma prática e intuitiva, com a opção de finalizar o pedido e ser redirecionado automaticamente para o WhatsApp para concluir a compra. Ideal para quem deseja uma experiência de pedido rápida e sem complicação, diretamente com o atendimento da pizzaria.

Jogo Web de Enigmas

Jogo de resolução de enigmas.

O Jogo de Enigmas é uma plataforma web onde os usuários podem criar e compartilhar enigmas para que outros jogadores tentem resolvê-los. Perfeito para brincadeiras de caça ao tesouro ao ar livre, o jogo permite que os jogadores sigam pistas e resolvam enigmas para alcançar uma chave que os levará à próxima pista ou ao "tesouro" final.

Bot com voz e inteligência artificial.

O ComoBot é um assistente virtual baseado em Inteligência Artificial que reconhece comandos de voz do usuário e responde em áudio em tempo real. Com uma interface intuitiva, o usuário pode simplesmente clicar e falar, permitindo interações rápidas e eficientes.

GeoCollet

Aplicativo Android para coleta de dados.

O GeoCollect é um aplicativo Android desenvolvido para facilitar a coleta local de dados de famílias, registrando informações essenciais como quantidade de membros e localização geográfica (latitude e longitude). O sistema permite que os dados coletados sejam exportados para uma planilha, possibilitando análises e tomadas de decisão mais eficientes.

SIGWEB - ITINGA

Sistemas de Informação Geográfica para Web (SIG Web)

O SIGWEB Itinga é um sistema de informação geográfica desenvolvido para visualização e análise de dados geoespaciais da região de Itinga. Ele permite a interação com mapas dinâmicos, exibição de camadas geográficas, consulta de dados em tabelas e análise de informações relevantes para planejamento e gestão territorial.
